## Overview

The `SimulationStore` manages all persistent data in a SQLite database. The default path is `output/collection_swarm.sqlite`. The store auto-creates the directory structure and initializes the schema on first use.

## Database Schema

### `runs` Table

Stores individual simulation results with denormalized judgment fields for efficient querying.

| Column | Type | Description |
|:-------|:-----|:------------|
| `id` | TEXT PK | Simulation ID |
| `status` | TEXT | completed, failed, running |
| `error_message` | TEXT | Error details if failed |
| `profile_id` | TEXT | Debtor profile ID |
| `strategy_id` | TEXT | Collector strategy ID |
| `conversation_model` | TEXT | Model for collector/debtor |
| `judge_model` | TEXT | Model for judge |
| `started_at` | TEXT | ISO timestamp |
| `ended_at` | TEXT | ISO timestamp |
| `turn_count` | INTEGER | Number of transcript messages |
| `ended_by` | TEXT | collector, debtor, stalemate, turn_limit |
| `transcript_json` | TEXT | JSON array of messages |
| `judge_reasoning` | TEXT | Judge's reasoning text |
| `payment_outcome` | TEXT | Enum value |
| `payment_probability` | REAL | 0–1 |
| `debtor_satisfaction` | REAL | 0–1 |
| `compliance_score` | REAL | 0–1 |
| `conversation_efficiency` | INTEGER | Turn count |
| `rapport_built` | REAL | 0–1 |
| `escalation_risk` | REAL | 0–1 |
| `end_reason` | TEXT | Free-text end reason |
| `constraint_violations_json` | TEXT | JSON array of strings |
| `total_input_tokens` | INTEGER | Total tokens consumed |
| `total_output_tokens` | INTEGER | Total tokens generated |
| `estimated_cost_usd` | REAL | Estimated cost |

### `elo_ratings` Table

Current Elo ratings for strategies and profiles.

| Column | Type | Description |
|:-------|:-----|:------------|
| `entity_type` | TEXT | "strategy" or "profile" |
| `entity_id` | TEXT | Strategy or profile ID |
| `conversation_model` | TEXT | Model context |
| `judge_model` | TEXT | Judge model context |
| `rating` | REAL | Current Elo rating |
| `games_played` | INTEGER | Total matches |
| `wins` | INTEGER | Win count |
| `losses` | INTEGER | Loss count |
| `draws` | INTEGER | Draw count |
| `updated_at` | TEXT | Last update timestamp |

**Primary key:** `(entity_type, entity_id, conversation_model, judge_model)`

### `elo_history` Table

Full history of every Elo rating change.

### `tournaments` Table

Tournament metadata and results.

### `evolved_strategies` Table

Strategies generated by the evolution system.

| Column | Type | Description |
|:-------|:-----|:------------|
| `id` | TEXT PK | Strategy ID |
| `generation` | INTEGER | Evolution generation |
| `parent_ids_json` | TEXT | JSON array of parent strategy IDs |
| `mutation_type` | TEXT | seed, llm |
| `mutation_description` | TEXT | Description of mutation |
| `strategy_json` | TEXT | Full strategy as JSON |
| `created_at` | TEXT | Creation timestamp |
| `culled_at` | TEXT | When culled (null if active) |

### `evolved_profiles` Table

Profiles generated by adversarial hardening. Same structure as `evolved_strategies` but with `parent_id` instead of `parent_ids_json`.

### `calibration_labels` Table

Human-provided scores for judge calibration.

| Column | Type | Description |
|:-------|:-----|:------------|
| `transcript_id` | TEXT | Reference to a simulation ID |
| `metric` | TEXT | Metric being scored |
| `human_score` | REAL | Human-assigned score (0–1) |
| `labeler_id` | TEXT | Who provided the score |
| `labeled_at` | TEXT | When labeled |

### `judge_prompt_variants` Table

Stores different judge prompt versions with their calibration scores.

## Key Operations

### Simulation CRUD

| Method | Description |
|:-------|:------------|
| `save_run(result)` | Save a single `SimulationResult` |
| `save_runs(results)` | Batch save using `executemany` |
| `get_run(run_id)` | Retrieve by ID |
| `list_runs(status)` | List all runs, optionally filtered by status |

### Analytics Queries

| Method | Description |
|:-------|:------------|
| `get_strategy_comparison(profile_id)` | Rank strategies by mean payment probability for a profile |
| `get_matrix_coverage()` | Count completed runs per matrix cell |
| `get_backfill_needed(target_reps, cells)` | Identify cells needing more repetitions |
| `get_best_transcript(profile_id, strategy_id)` | Best transcript by payment probability then compliance |
| `get_all_transcripts(profile_id, strategy_id)` | All transcripts for a combination |
| `get_compliance_summary(profile_id, strategy_id)` | Mean compliance score and escalation risk |
| `get_cost_summary()` | Total simulations, tokens, and cost |
| `count_by_status()` | Count runs grouped by status |
| `get_combo_runs(...)` | Filtered runs for a specific combination |
| `get_performance_by(dimension)` | Aggregate performance by profile, strategy, or model |

| Method | Description |
|:-------|:------------|
| `get_elo_ratings(entity_type, ...)` | List current ratings, optionally filtered |

| `save_elo_update(update, tournament_id)` | Apply a rating change and record history |
| `get_elo_history(entity_id)` | Full rating history for an entity |

## Schema Migration

The store uses `_ensure_column()` to add columns that may be missing in older databases:

```python
def _ensure_column(self, connection, table, column, definition):
    columns = {row["name"] for row in connection.execute(f"PRAGMA table_info({table})").fetchall()}
    if column not in columns:
        connection.execute(f"ALTER TABLE {table} ADD COLUMN {column} {definition}")
```

This is used to add `conversation_model` and `judge_model` columns to `elo_ratings` and `elo_history` tables, enabling model-scoped ratings.

## Win/Loss/Draw Classification

Elo updates classify outcomes using a draw threshold of 0.05:

| Condition | Result |
|:----------|:-------|
| `effective_score > 0.55` | Win |
| `effective_score < 0.45` | Loss |
| `0.45 ≤ effective_score ≤ 0.55` | Draw |
